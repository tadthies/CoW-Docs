# Overview

The **Overview** page gives a snapshot of your devices and warranties. The cards shown depend on whether you have any devices yet.

## Dashboard

| Card                                   | Description                                                                                                                                                                                             |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No integrations corralled yet          | Shown until you set up an integration. Click **Wrangle Integrations** to open the [integrations](../integrations/ "mention") page.                                                                       |
| Welcome                                | Shown until you have devices. Click **Start Onboarding** to set up an integration on the [integrations](../integrations/ "mention") page, or add devices with a [csv-import.md](../devices/csv-import.md "mention"). |
| Devices                                | The total number of devices. Click **View all** to open the [devices](../devices/ "mention") page.                                                                                                        |
| Upcoming Expiring Warranties           | Devices whose warranty expires within 30 days. Click **View all** to open the devices page filtered to those devices.                                                                                  |
| Expired warranties                     | Devices whose warranty has expired. Click **View all** to open the devices page filtered to those devices.                                                                                             |
| Messages                               | Your latest messages. Click **View all** to open the [messages.md](messages.md "mention") page, which lists every message your organisation has received.                                              |
| Warranty Status                        | A donut chart of your warranties by category. The categories are described in [#warranty-status-categories](./#warranty-status-categories "mention").                                                  |

The **Devices**, **Upcoming Expiring Warranties**, **Expired warranties** and **Warranty Status** cards appear once you have at least one device. **Messages** is always shown.

### Warranty Status Categories

| Category                            | Description                                  |
| ----------------------------------- | -------------------------------------------- |
| Current                             | Devices with an active warranty.             |
| Almost Expired (less than 30 Days)  | Warranties expiring within the next 30 days. |
| Expired                             | Warranties that have already expired.        |
| Unknown                             | Devices with an unknown warranty status.     |
